# The file types spacebar takes Space for in Finder. build.sh reads this file for two things:
#   - the preview extension's QLSupportedContentTypes: every `claim` and every `declare`d type, plus md.spacebar.qlmanage
#   - the app's UTImportedTypeDeclarations: every `declare`, after the hand-written Markdown declaration in App/Info.plist
#
#   claim <UTI>
#       A type the system already declares.
#   declare <ext[,ext...]> <conforms-to[,...]> <description>
#       An extension the system has no type for (it resolves to a dyn.* ID, which no extension can claim). The app imports
#       md.spacebar.type.<first ext> for it. An imported type never overrides a type the system or another app exports.
#
# Quick Look hands a third-party extension a file only when its exact type is claimed: a parent type (public.source-code,
# public.text) never routes, and types Apple previews itself never do (plain text, HTML, CSV, PDF, images, movies, audio,
# RTF, Word, .ts streams, certificates, disk images). Those are not listed. Neither are .mkv, .flv, .ogv, .opus and .webm:
# AVFoundation cannot play them, so spacebar would show no more than Finder does.
